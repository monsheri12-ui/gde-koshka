# Где кошка? — тибетский в трёх комнатах

Браузерная игра для изучения тибетских послелогов. **Версия 6.0:** новые кошки, смешанная практика и удобное управление на телефоне.

**[Открыть игру](https://monsheri12-ui.github.io/gde-koshka/)**

## Что нового

- Шесть нарисованных кошек и первоначальная пушистая спутница. Выбор кошки сохраняется для всех комнат.
- Режим **«Микс»** чередует три типа заданий: определить положение кошки, найти место по тибетской фразе и вставить послелог в предложение.
- Короткие раунды на **6 вопросов**, а также привычные 12 и 24.
- **Два или четыре варианта ответа** для постепенного усложнения.
- **«Мои результаты»** показывает точность по каждому послелогу. **«Сложные для меня»** помогает вернуться к темам с ошибками.
- Компактные настройки, крупные кнопки и закреплённая комната при тренировке на телефоне.
- Мягкая анимация кошки; при включённом уменьшении движения в системе анимации отключаются.
- Тренировка предложения из банка теперь начинается именно с выбранного предложения.
- До попытки ответа скринридер получает описание задания без правильного ответа.

## Как играть

1. Выберите комнату и кошку.
2. Освойте послелоги в «Словарике».
3. Перейдите в «Где кошка?», «Посади кошку», «Предложения» или «Микс».
4. В настройках раунда выберите число вопросов, два или четыре ответа и лимит времени.
5. Нажмите «Новый раунд». Для раунда на время нажмите «Начать».

После ответа можно спокойно прочитать перевод; следующий вопрос появляется по кнопке. Открытие выбора кошки, результатов, банка или источников ставит таймер на паузу. Для продолжения нажмите «Продолжить».

## Учебный материал и сохранения

Сохранены три комнаты, 12 послелогов, банк из 144 предложений и 46 начальных вариантов. Встроенные учебные данные, иллюстрации комнат и слои мебели сохранены из исходной версии 5.1.

Сохранения и рекорды версии 5.1 продолжают использовать тот же ключ браузерного хранилища. Результаты с двумя и четырьмя вариантами, разной длиной раунда и разным таймером учитываются отдельно. Прогресс остаётся на устройстве и в браузере, где вы играете.

## Запуск без сайта

Скачайте репозиторий целиком и откройте index.html в браузере. Распакуйте и сохраните все файлы проекта в одной папке. Установка и сборка не требуются.

Шрифты подключаются через Google Fonts. Без интернета используется подходящий системный шрифт.

## Исходная версия

Пять файлов из предоставленного архива Gde_koshka_Rooms_v5_1_timer.zip сохранены без изменений: исходный HTML, инструкция, JSON-банк и два PNG-превью. Эти превью относятся к версии 5.1.
